01

Tentang panduan

Cara menggunakan manual ini

Panduan ini mengikuti urutan pekerjaan yang umum dilakukan, mulai dari menyiapkan router sampai memproses pembayaran pelanggan.

Siapa yang menggunakan

  • Admin untuk konfigurasi dan pengawasan penuh.
  • Mitra untuk voucher dan pelanggan yang ditugaskan.
  • Biller untuk penagihan serta komisi.
  • Pelanggan untuk portal mandiri.

Penanda dalam panduan

LANGKAH Urutan tindakan yang perlu dilakukan.

PERHATIAN Risiko atau syarat sebelum melanjutkan.

HASIL Kondisi yang seharusnya terlihat.

Catatan tampilan: menu yang terlihat bergantung pada peran akun dan router yang dipilih. Beberapa fungsi hanya aktif ketika RouterOS terhubung.

Urutan awal yang disarankan

  1. Masuk sebagai AdminPastikan kredensial aplikasi tersedia.
  2. Tambahkan dan hubungkan routerIsi alamat API, pengguna RouterOS, serta data hotspot.
  3. Atur profil layananBuat profil voucher dan profil billing sesuai kebutuhan.
  4. Tambahkan pengguna operasionalBuat Mitra atau Biller setelah router siap.

Persiapan

Sebelum mulai menggunakan aplikasi

Siapkan akses

  • Alamat aplikasi Emmeril Hotspot.
  • Username dan password Admin.
  • Alamat IP atau IP Cloud MikroTik.
  • Username dan password API RouterOS.
  • Port API RouterOS sudah diaktifkan.
  • Koneksi aplikasi menuju router tersedia.

Untuk integrasi

  • Token Fonnte dan perangkat WhatsApp aktif.
  • Akun Midtrans beserta Merchant ID, Server Key, dan Client Key.
  • Nomor HP pelanggan tersimpan dengan benar.
  • Profil layanan serta harga telah disepakati.

Pemeriksaan RouterOS

PemeriksaanTujuan
API aktifAplikasi membutuhkan layanan API RouterOS untuk membaca dan mengubah data.
Pengguna APIHak pengguna harus cukup untuk menu yang akan dikelola.
Waktu routerTanggal dan waktu yang benar diperlukan untuk masa aktif, scheduler, dan laporan.
Hotspot atau PPPoEKonfigurasi dasar layanan perlu tersedia sebelum akun pelanggan dibuat.
Jangan membagikan password Admin, password router, token Fonnte, Server Key Midtrans, atau password pemulihan backup melalui grup umum.

Akses aplikasi

Login sebagai Admin

Halaman login Admin. Jangan menyimpan password pada komputer bersama.

  1. Buka alamat aplikasiGunakan browser pada komputer atau ponsel yang memiliki akses ke server.
  2. Masukkan UsernameGunakan akun Admin, Mitra, atau Biller yang telah dibuat.
  3. Masukkan PasswordPeriksa huruf besar, huruf kecil, dan karakter yang digunakan.
  4. Tekan LoginSistem mengarahkan akun sesuai perannya.
Hasil: Admin masuk ke area router atau dashboard. Mitra masuk ke router yang ditugaskan. Biller masuk ke Invoice Unpaid.

Konfigurasi awal

Menambah dan menghubungkan router

Router›Tambah Router
  1. Buka menu RouterTekan Tambah Router pada daftar router.
  2. Isi Session NameGunakan nama unik yang mudah dikenali, misalnya nama lokasi.
  3. Isi data MikroTikMasukkan IP MikroTik, username, dan password API.
  4. Isi Router DataTentukan Hotspot Name, DNS Name, mata uang, interval reload, idle timeout, dan interface trafik.
  5. Tekan SaveSimpan konfigurasi terlebih dahulu.
  6. Uji koneksiGunakan Ping untuk memeriksa jalur jaringan, lalu Connect untuk membuka router.
KolomKeterangan
IP MikroTikAlamat IP atau IP Cloud yang dapat dijangkau server aplikasi.
DNS NameNama DNS dari Hotspot Server Profile.
Traffic InterfaceNomor interface yang dipakai oleh pemantau trafik.
Live ReportAktifkan jika laporan langsung diperlukan.
Jika Not Connected: periksa IP, user, password, port API, firewall, dan jalur VPN. Simpan perubahan sebelum mencoba Connect kembali.

Hotspot

Membuat profil voucher

Hotspot›User Profile›Tambah
  1. Isi NameGunakan nama tanpa spasi agar mudah dipakai pada voucher dan laporan.
  2. Pilih Address PoolPilih pool RouterOS yang sesuai atau none bila tidak digunakan.
  3. Atur Shared UsersTentukan jumlah perangkat yang boleh memakai satu akun secara bersamaan.
  4. Isi Rate LimitGunakan format upload/download, misalnya 512k/1M.
  5. Pilih Expired ModeGunakan None untuk profil pelanggan bulanan. Gunakan mode selain None untuk voucher.
  6. Lengkapi harga dan masa aktifIsi Validity, Grace Period bila muncul, Price, dan Selling Price.
  7. Tentukan Lock UserAktifkan jika akun perlu dikunci ke MAC perangkat pertama.
  8. Tekan SaveProfil tersimpan pada RouterOS.
Profil voucher: Expired Mode selain None. Profil ini tersedia pada Generate User dan portal pembelian voucher.
Profil billing: Expired Mode None. Profil ini tersedia saat menambah layanan pelanggan.

Voucher

Membuat voucher dalam jumlah banyak

Voucher›Voucher List›Generate
  1. Pilih server hotspotGunakan all atau server tertentu sesuai lokasi.
  2. Isi jumlah voucherTentukan Qty sesuai kebutuhan. Periksa batas stok Mitra bila digunakan.
  3. Pilih mode akunMode voucher memakai username yang sama dengan password. Mode user/password membuat keduanya berbeda.
  4. Atur panjang dan karakterPilih jumlah karakter, huruf, angka, atau kombinasi yang tersedia.
  5. Tambahkan prefixPrefix membantu membedakan batch atau area penjualan.
  6. Pilih profileHanya profil dengan Expired Mode selain None yang dapat digunakan.
  7. Isi batas tambahanGunakan Time Limit, Data Limit, dan komentar bila memang diperlukan.
  8. SimpanSistem membuat akun pada RouterOS dan mengarahkan kembali ke daftar voucher.
Sebelum menekan Generate: periksa Qty, profile, harga, dan pola username. Pembuatan batch langsung menambah akun pada router.
Untuk Mitra: komentar kepemilikan ditambahkan oleh sistem agar voucher dapat dihitung dan dibatasi sesuai akun Mitra.

Voucher

Mencari, memeriksa, dan mencetak voucher

Voucher›Voucher List

Memeriksa daftar

  1. Pilih profile atau gunakan AllFilter membantu menemukan batch tertentu.
  2. Gunakan pencarianCari username, komentar batch, atau informasi yang tersedia.
  3. Periksa status pemakaianBedakan voucher belum terpakai dari voucher yang sudah mulai digunakan.
  4. Pilih voucherGunakan kotak pilihan untuk tindakan pada beberapa akun.

Mencetak voucher

  1. Buka Print Center atau Quick PrintPilih voucher dan format cetak.
  2. Periksa pratinjauPastikan logo, username, password, harga, dan masa berlaku terbaca.
  3. Pilih ukuranGunakan template standar, kecil, atau thermal sesuai printer.
  4. Cetak atau simpan sebagai PDFGunakan dialog cetak browser.

Jumlah Voucher

Gunakan ringkasan berdasarkan profile untuk melihat total dan stok belum terpakai.

Hapus dengan hati-hati

Penghapusan voucher memengaruhi akun di RouterOS. Pastikan batch yang dipilih benar.

Hotspot

Mengontrol sesi dan perangkat

MenuKegunaanTindakan umum
Hotspot ActiveMelihat pengguna yang sedang terhubung.Putuskan sesi jika akun perlu login ulang atau koneksi macet.
MAC LocksMelihat akun yang terkunci ke perangkat.Reset kunci saat pelanggan mengganti perangkat.
HostsMelihat perangkat yang terdeteksi oleh hotspot.Periksa alamat IP, MAC, dan status perangkat.
IP BindingsMengelola pengecualian atau pengikatan IP hotspot.Tambah, ubah, aktifkan, atau nonaktifkan aturan sesuai kebijakan jaringan.
CookiesMelihat cookie login hotspot.Hapus cookie jika perangkat perlu memasukkan kredensial kembali.

Mengganti perangkat pelanggan

  1. Pastikan akun yang benarCocokkan username dengan pelanggan.
  2. Putuskan sesi aktifLakukan jika akun masih terhubung pada perangkat lama.
  3. Buka MAC LocksReset kunci untuk username tersebut.
  4. Hapus cookie bila perluLakukan jika browser tetap menggunakan sesi lama.
  5. Minta pelanggan login ulangGunakan voucher atau kredensial yang sama pada perangkat baru.
Reset MAC tidak mengganti password dan tidak memperpanjang masa aktif voucher.

PPPoE

Mengelola profil, akun, dan sesi PPPoE

Membuat profil PPPoE

PPPoE›PPPoE Profiles›Tambah
  1. Isi nama profilGunakan nama paket yang mudah dikenali.
  2. Atur parameter layananIsi local address, remote address, rate limit, dan parameter RouterOS lain yang diperlukan.
  3. Tentukan metadata billingUntuk pelanggan bulanan, gunakan profil yang dapat dikelola Billing.
  4. Simpan profilPeriksa kembali pada daftar profil.

Membuat akun PPPoE

PPPoE›PPPoE Secrets›Tambah
  1. Isi username dan passwordGunakan identitas akun yang unik.
  2. Pilih service PPPoEPilih profil paket yang sesuai.
  3. Tambahkan komentarGunakan nama pelanggan agar akun mudah ditelusuri.
  4. Simpan dan uji koneksiLihat PPPoE Active setelah perangkat pelanggan tersambung.
Untuk pelanggan yang akan ditagih melalui aplikasi, gunakan menu Pelanggan lalu Tambah Layanan. Cara tersebut mengaitkan akun RouterOS ke identitas dan invoice.

Billing

Menandai lunas dan mengaktifkan layanan

Billing›Invoice Unpaid›Tandai Lunas
  1. Pastikan pembayaran diterimaCocokkan nama, nomor invoice, jumlah, dan metode pembayaran.
  2. Tekan Tandai LunasBaca konfirmasi bahwa semua layanan pelanggan akan diaktifkan.
  3. Setujui konfirmasiSistem mencatat pembayaran dan menjalankan aktivasi.
  4. Periksa status layananStatus pelanggan seharusnya kembali aktif jika RouterOS menerima perubahan.
  5. Periksa notifikasiJika Kirim setelah pembayaran aktif, konfirmasi langsung diproses tanpa menunggu jam kerja.

Pembayaran manual

Petugas menekan Tandai Lunas setelah verifikasi dana.

Pembayaran gateway

Jika pembayaran diterima tetapi aktivasi belum selesai, gunakan Aktifkan Layanan atau Coba Lagi Aktivasi.

Jangan menandai lunas berdasarkan bukti yang belum diverifikasi. Status lunas masuk ke laporan dan dapat mengaktifkan seluruh layanan pelanggan.

Portal pelanggan

Login OTP, pembayaran, dan voucher

Halaman masuk portal pelanggan menggunakan nomor HP yang terdaftar.

  1. Masukkan nomor handphoneNomor harus sama dengan data identitas pelanggan.
  2. Tekan Kirim Kode OTPFonnte mengirim kode enam digit melalui WhatsApp.
  3. Masukkan OTPTekan Verifikasi dan Masuk.
  4. Pilih kebutuhanPelanggan dapat mengganti password Hotspot, membayar langganan, membeli voucher, atau melihat riwayat.
  5. Selesaikan pembayaranSetelah voucher lunas melalui Midtrans, kode voucher dibuat otomatis dan tampil di portal.
  6. Tekan KeluarLakukan setelah selesai, terutama pada perangkat bersama.
Portal membutuhkan nomor pelanggan yang benar. Pembayaran daring dan pembelian voucher membutuhkan Payment Gateway aktif.

Konfirmasi bayar: jika Kirim setelah pembayaran aktif, pesan langsung diproses setelah invoice lunas.
Pengingat terjadwal: mengikuti konfigurasi otomasi dan waktu kerja yang berlaku.

Pembayaran daring

Mengatur Midtrans

Settings›Payment Gateway
  1. Pilih modeGunakan Sandbox untuk pengujian. Gunakan Production hanya dengan kredensial produksi.
  2. Isi Merchant IDSalin nilai dari akun Midtrans.
  3. Isi Server Key dan Client KeyPastikan pasangan key sesuai dengan mode yang dipilih.
  4. Atur masa berlakuPilih durasi link invoice sesuai kebijakan pembayaran.
  5. Aktifkan pembayaran onlineCentang status setelah konfigurasi benar.
  6. Tekan Simpan PengaturanKosongkan key jika ingin mempertahankan key yang sudah tersimpan.
  7. Tekan Tes MidtransPastikan uji koneksi berhasil sebelum portal dipakai pelanggan.
Jangan mencampur mode. Key Sandbox tidak boleh dipakai pada Production, dan sebaliknya. Pergantian mode dapat membuat link pembayaran lama tidak berlaku.
Portal memakai Snap pada browser. Server Key dipakai oleh server aplikasi, sedangkan Client Key dipakai saat tampilan pembayaran dibuka.

Laporan

Melihat penjualan dan pendapatan

Laporan›Semua / Hotspot / PPPoE
  1. Pilih jenis laporanSemua menggabungkan layanan. Hotspot dan PPPoE membatasi jenis transaksi.
  2. Pilih hari, bulan, dan tahunGunakan periode yang sama saat membandingkan dashboard.
  3. Pilih profile bila diperlukanFilter ini membantu menilai paket tertentu.
  4. Gunakan pencarianCari username, komentar, profile, atau informasi transaksi.
  5. Buka ResumeGunakan ringkasan untuk melihat total periode yang dipilih.
  6. Cetak laporanGunakan fungsi cetak yang tersedia untuk arsip atau rekonsiliasi.

Pemisahan yang perlu diperhatikan

  • Pendapatan voucher dan pembayaran pelanggan memiliki sumber data berbeda.
  • Harga dasar dan harga jual digunakan untuk menghitung hasil penjualan voucher.
  • Transaksi portal yang lunas perlu muncul satu kali, bukan dihitung ulang secara manual.
  • Pendapatan Mitra dilihat dari penugasan dan penanda kepemilikan data.
Jangan menghapus record laporan sebelum rekonsiliasi selesai dan backup tersedia.

Urutan pemeriksaan saat terjadi gangguan

  1. Periksa status routerPastikan aplikasi masih Connected.
  2. Baca log yang paling dekat dengan waktu kejadianCatat pesan sebelum melakukan perubahan.
  3. Periksa sesi atau schedulerCocokkan username dan status layanan.
  4. Uji satu perubahanHindari banyak perubahan sekaligus agar penyebab tetap dapat ditelusuri.

SOP operasional

Pemeriksaan harian dan bulanan

Setiap awal hari

  • Periksa koneksi router.
  • Periksa log sistem terbaru.
  • Lihat invoice jatuh tempo dan pelanggan terisolasi.
  • Periksa status perangkat Fonnte.
  • Pastikan transaksi gateway yang masuk sudah diproses.

Setiap akhir hari

  • Cocokkan pembayaran manual dengan Invoice Paid.
  • Tinjau kegagalan notifikasi atau aktivasi.
  • Periksa penjualan voucher hari ini.
  • Catat gangguan yang belum selesai.

Setiap minggu

  • Jalankan backup.
  • Periksa stok voucher Mitra.
  • Tinjau akun tidak aktif.
  • Periksa log yang berulang.

Setiap bulan

  • Ekspor Invoice Paid.
  • Rekonsiliasi pendapatan pelanggan dan voucher.
  • Periksa komisi Mitra dan Biller.
  • Uji pemulihan backup pada prosedur yang aman.
Tentukan satu penanggung jawab untuk rekonsiliasi dan satu penanggung jawab teknis. Pembagian ini mengurangi perubahan ganda pada data yang sama.
